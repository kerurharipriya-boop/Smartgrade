SmartGrade – AI-Powered Rubric-Based Short-Answer Grader

Project Overview

SmartGrade is an AI-powered educational assessment system designed to make short-answer evaluation faster, more consistent, and transparent.

It evaluates student answers using configurable rubrics and provides meaningful feedback based on the expected answers.

Problem Statement

Manual evaluation of short-answer questions takes time and may lead to inconsistent marking. Changes in evaluation criteria also make regrading difficult.

Proposed Solution

SmartGrade aims to automate short-answer assessment using AI, semantic similarity, and configurable evaluation rubrics.

Key Features

- Batch upload of student answers using CSV files.
- Evaluation using model answers and configurable rubrics.
- Criterion-wise marks and evidence-based explanations.
- Constructive feedback for students.
- Reliability analysis and human-AI score comparison.
- Dynamic rubric modification and regrading.
